How It Works

The marching squares algorithm creates smooth contours by analyzing grid cells. Each cell's corners are evaluated to determine if they're inside or outside the metaball field, then appropriate line segments are drawn to create organic shapes.

  • 10 animated metaballs with random sizes and velocities
  • Real-time grid-based contour generation
  • Adjust grid size for different levels of detail
