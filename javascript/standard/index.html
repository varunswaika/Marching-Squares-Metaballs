Marching Squares Metaballs

Interactive visualization of the marching squares algorithm

FPS: 60

How It Works

The marching squares algorithm creates smooth contours by analyzing grid cells. Each cell's corners are evaluated to determine if they're inside or outside the metaball field, then appropriate line segments are drawn to create organic shapes.

Features

  • Adjustable grid resolution for detail control
  • Dynamic ball count (1-20 metaballs)
  • Variable animation speed (0.1x - 3x)
  • Seven color schemes to choose from
  • Pause/play controls for analysis
  • Filled mode for solid rendering
  • Real-time FPS monitoring
