Optimized Marching Squares Metaballs

Recursive subdivision for adaptive grid refinement

FPS: 60

Optimization Technique

This version uses recursive subdivision to adaptively refine the grid only where needed. Instead of evaluating every small cell, it starts with a coarse grid and subdivides only regions with interesting features, significantly improving performance.

  • Variable animation speed (0.1x - 3x)
  • Seven color schemes to choose from
  • Pause/play controls for analysis
  • Filled mode for solid rendering
  • Real-time FPS monitoring
  • Recursive refinement only where needed
